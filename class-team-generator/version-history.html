What's new in Class Team Generator.

Version 1.2

In development · Not yet released · Updated September 30, 2026

  • Center move and remove icons and align group actions above student actions.
  • Name and rename classes in a small dialog; place compact group-name controls beside the class dropdown and consolidate status instructions.
  • Click the picker visualization (or press Enter/Space) to pick; remove extra instructions and the separate pick button.
  • Copy a transparent image directly using the last export settings.
  • Show first names, last names, or both in groups, the picker, and exports; preserve full roster names and remember the selection.

Version 1.1

Committed as 1707caf · GitHub release not confirmed

  • Reorder groups by dragging. Mark students or groups absent, and restore them individually or all at once. The picker skips absences.
  • Generate animal, superhero, space, or mathematician group names; mathematicians use short names such as Noether and Euler.
  • Save and restore the workspace, grouping rules, attendance, and settings between sessions and through JSON export/import.
  • Export transparent PNGs with a white preview and the class name as the title; remember export settings. JPEG exports remain white.
  • Compact controls, wider class selection, and group-colored move and remove buttons. Fix dark mode overriding custom backgrounds.
  • Collapse the picker to a slim side bar. Add naturally bouncing balls, a robot speech bubble, and a curved hat.
  • Add version history in the footer.

Version 1.0

Initial teaching-app collection version

  • Generate class groups with custom names, grouping rules, and student dragging.
  • Save named classes, share groups, and export class data and images.
  • Choose students or groups with spinner, ball machine, robot, and hat picker visuals.
