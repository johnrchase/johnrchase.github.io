Edit Names

Enter one name per line: First Last, or Last, First (helpful for compound last names). Single names work in every display mode. Blank lines are ignored.

Grouping Rules

Put one rule on each line and separate names with a |. Names must match the class list. You may put more than two names on a line. For “should be together,” all names on that line stay together. For “can’t be together,” every name on that line is kept apart from the others.

Example: Avery | Jordan
